# GPT-2 small (124M) in Bend

Inference of GPT-2 small written in Bend: pre-tokenizer, BPE tokenizer with the 50,000 official rules (the `bend-ml-bpe-tokenizer` package, roundtrip proved), 12 transformer layers with a key/value cache, and greedy generation. The matrices use `bend-ml-tensor-array`, with the shape in the type.

Two implementations, with identical output:

- `fast.bend` (v1.3.2): weights in row bands (`Bands`) when there are more than 2 threads, so each matrix · vector product runs its bands in parallel without copying the weights. Every band is read straight into its array from its own range of the weight file (`bend-ml-binary-read`, since v1.3.0), which is size-checked first: the weights load in 0.8 s on one thread instead of 4.7. On an idle machine, 36 forward passes take 3.5 s on 16 threads and 4.7 s on one, about 0.1 to 0.13 s per token; see `BENCHMARK.md`.
- `gpt2.bend` (v0.2): matrices as lists, kept as the baseline. ~3 s per token.

## Run (from the repository root)

```bash
reference/.venv/bin/python reference/gpt2_prep.py          # downloads nothing; converts demos/gpt2/data/model.safetensors
reference/.venv/bin/python reference/gpt2_prep.py --split  # per-tensor weights (Conv1D already transposed)

bend demos/gpt2/fast.bend -o /tmp/gpt2_fast
/tmp/gpt2_fast "The capital of France is" 8
```

The weights (`model.safetensors`), `vocab.json` and `merges.txt` come from <https://huggingface.co/openai-community/gpt2>; they go in `demos/gpt2/data/` (outside git).

## Verification

- **Tokenizer**: `reference/test_gpt2_tok.py` compares with `tiktoken` on 79 texts: 49 written by hand (ASCII, contractions, numbers, spaces and newlines, accents, Cyrillic, CJK, emoji) and 30 random Unicode strings. All 79 are identical.
- **Model**: `reference/test_gpt2.py` runs the same model in PyTorch with the same weights on 11 prompts; the generated ids and text are identical and the logits agree within 3.2e-4 (see `BENCHMARK.md`).

## Known limits

- The pre-tokenizer decodes UTF-8 and classifies each code point with `unicode.bend`, a table generated by `reference/gen_unicode_table.py` from the `regex` module (`\s`, `\p{L}`, `\p{N}`). Code points above U+1FFFF and invalid UTF-8 count as letters. The result matches `tiktoken` on every test text, including 180 random Unicode strings.
- Greedy generation only (no temperature or sampling).
- Memory: the 124 M weights live in trees of nodes. `fast.bend` reads each weight file in 1 MB blocks and writes them straight into the arrays: peak resident memory ~0.9 GB (~2.3 GB when each tensor was first a list). The process reserves ~41 GB of address space, which is not memory in use. Measure with `scripts/peak_rss.sh`.
